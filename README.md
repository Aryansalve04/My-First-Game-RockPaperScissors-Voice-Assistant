# My-First-Game-RockPaperScissors-Voice-Assistant

Built this **Rock Paper Scissors game** in Python while just messing around and learning stuff.  
The computer picks its move, you pick yours, and a **voice assistant shouts the result**.  
Simple, fun, and interactive—perfect for leveling up Python skills.

## ⚡ Features

- Play **Rock Paper Scissors** vs computer  
- Supports **full words** (`rock`, `paper`, `scissor`) & **short cuts** (`r`, `p`, `s`)  
- **Voice feedback** after every round 🎤  
- Handles **Win / Lose / Draw**  
- Super beginner-friendly—good for learning Python
